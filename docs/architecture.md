# Architecture

## Overview

Garmin Coach is a self-hosted, single-user AI coaching agent. It connects Garmin Connect fitness data to a conversational Telegram interface powered by Google ADK and Gemini.

```
Telegram User
     │
     ▼
TelegramBot (src/core/telegram_bot.py)
  • single-owner access control
  • /setup, /sync commands
     │
     ▼
AdkCoachRuntime (apps/garmin_coach/src/coach_adk/runtime.py)
  • Runner + DatabaseSessionService (persistent sessions)
  • strict startup checks
     │
     ▼
root_agent (apps/garmin_coach/src/coach_adk/agent.py)
  • Gemini 2.5 Flash
  • SkillToolset: 5 filesystem skills + 5 FunctionTools
     │
     ├── get_context_data    → DataTools / DatabaseTools
     ├── analyze_fitness     → analytics/fitness_analysis.py
     ├── weekly_plan         → analytics/weekly_plan_builder.py
     ├── query_data          → analytics/sql_guardrails.py (NL2SQL)
     └── render_chart        → tools/chart_tools.py
```

## Key Design Decisions

### Single-user by design

This is a self-hosted personal tool, not a SaaS product. Access control is enforced at the Telegram layer: the first private message binds the bot to one owner. All subsequent messages from any other user or chat are rejected. This removes multi-tenancy complexity while keeping the codebase clean and auditable.

### Google ADK with filesystem skills

The agent uses Google's Agent Development Kit (ADK) with a `SkillToolset` backed by Markdown skill files. Each skill (`coach-context`, `fitness-analysis`, `weekly-plan`, `query-data-guarded`, `chart-render`) is a self-contained instruction document with frontmatter declaring which tools it activates. This separates agent knowledge from agent wiring and makes skills easy to read, test, and swap independently.

### Persistent sessions via DatabaseSessionService

ADK sessions are stored in SQLite (default) or PostgreSQL using `DatabaseSessionService`. The database URL must use an async driver (`sqlite+aiosqlite://`, `postgresql+asyncpg://`). Startup fails hard if the session database is unreachable.

### NL2SQL with guardrails

The `query_data` tool translates natural-language questions into parameterized SQL. All queries are validated server-side before execution: `SELECT`-only, single statement, no blocked keywords, mandatory `:user_id` parameter, `LIMIT ≤ 200` (waived for aggregate queries). A configurable Gemini model generates the SQL; a separate validation layer enforces the policy.

### Chart generation with spec-driven dispatch

Charts are generated by passing a `key=value` spec string from the agent to the chart tool. The agent selects the chart type based on user intent using a decision guide in the skill file. This avoids hardcoding chart selection in agent logic and lets the model reason about visualization independently.

## Data Flow — Typical Coaching Request

```
User: "What was my weekly load last week?"

1. TelegramBot.handle_message → AdkCoachRuntime.process_message
2. root_agent receives message, loads "query-data-guarded" skill
3. skill activates query_data FunctionTool
4. query_data calls run_guarded_nl2sql:
   a. Gemini generates SQL from question
   b. sql_guardrails validates: SELECT-only, parameterized, LIMIT
   c. Parameterized query executed against PostgreSQL
5. Agent formats result and replies via Telegram
```

## Environment Variables

| Variable | Required | Default | Description |
|---|---|---|---|
| `GOOGLE_API_KEY` | yes | – | Gemini API key |
| `TELEGRAM_BOT_TOKEN` | yes | – | Telegram bot token |
| `SECRET_KEY` | yes | – | Fernet key for credential encryption |
| `DB_HOST` | yes | `localhost` | PostgreSQL host |
| `ADK_SESSION_DB_URL` | no | `sqlite+aiosqlite:///./data/adk_sessions.db` | Async session DB |
| `ADK_SESSION_STRICT_STARTUP` | no | `true` | Fail on session DB error |
| `ENABLE_NL2SQL` | no | `true` | Enable NL2SQL tool |
| `ENABLE_CHARTS` | no | `true` | Enable chart generation |
| `TELEGRAM_OWNER_USER_ID` | no | – | Pre-bind owner (recommended for production) |
| `TELEGRAM_BIND_ON_FIRST_START` | no | `true` | Allow first-message owner binding |
